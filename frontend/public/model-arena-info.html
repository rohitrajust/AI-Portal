Give it any topic, and two independent AI models debate it in real time — arguing back and forth for several rounds — while a neutral third AI judges the exchange and declares a winner.

✨ What It Does

  • 📝 Takes any topic you type in
  • 🤖 Two different LLMs debate it turn by turn
  • 🔁 Each reply becomes the next prompt for the other model
  • 💬 Responses stream in live, like a real chat
  • ⚖️ A neutral AI judge reviews the full debate
  • 🏆 Declares a winner with reasoning

How to Use

1️⃣ Enter a Topic

Type any subject you'd like the two models to debate.

2️⃣ Set Rounds

Choose how many back-and-forth exchanges to run (default: 5).

3️⃣ Start Debate

Model A opens with its stance on the topic.

4️⃣ Watch It Unfold

Model B responds, then Model A replies again, streaming live.

5️⃣ See the Verdict

An independent AI judge reviews the debate and declares a winner.

Best Practices

🎯 Be Specific

Clear, focused topics produce sharper, more interesting debates.

🔢 Start Small

Try 3–5 rounds first before running longer debates.

🌐 Stable Connection

Each round calls external AI APIs, so a steady connection helps.

🔍 Read the Verdict

The judge's reasoning often reveals the strongest arguments made.
